# MITRE Attack Chain

Evidence-grounded CVE analysis that combines NVD, a pinned local CVE List V5 snapshot,
trusted security advisories, FH Genie structured extraction, and Neo4j provenance.

## Current scope

Implemented: normalized CVE metadata, pinned CWE/CAPEC synchronization, trusted advisory
retrieval, evidence-linked exploit-step extraction, Neo4j storage, FastAPI, and CLI. ATT&CK
mapping, validation, and final attack-path output belong to later phases.

## Requirements and installation

- Python 3.11+
- Network access to NVD, MITRE dataset downloads, trusted advisory domains, and FH Genie
- Docker with Compose for the local Neo4j service

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
cp .env.example .env
```

Configure Neo4j and FH Genie in `.env`. An NVD API key is optional but recommended for
higher rate limits. Never commit `.env`.

Start Neo4j and explicitly synchronize the pinned datasets:

```bash
docker compose up -d neo4j
python -m app.data.sync_mitre
```

Use `--download-only` to verify and extract the datasets without loading Neo4j. Runtime
startup never downloads datasets. Archives and the generated checksum manifest are stored
under ignored `data/` paths.

## Run

```bash
python -m app.cli analyze CVE-2026-22306
uvicorn app.main:app --reload
```

Then call:

```bash
curl -X POST http://127.0.0.1:8000/api/cve-analysis \
  -H 'content-type: application/json' \
  -d '{"cve_id":"CVE-2026-22306"}'
```

## Design notes

NVD is the primary per-CVE API. A pinned CVE List V5 snapshot supplies official fallback and
supplementary fields; CVE.org HTML is never scraped. Tagged advisory references are prioritized,
and untagged references require a configured allowlisted domain. Advisory requests reject private
networks, revalidate redirects, and enforce content and size limits.

FH Genie receives advisory text as untrusted evidence. Each returned exploit step must cite an
exact excerpt from a fetched source. Invalid output is retried once, then represented as an empty
step list with a warning. No CWE/CAPEC relationship is generated by the model.
